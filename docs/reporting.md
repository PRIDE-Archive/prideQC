# Reporting with pmultiqc / MultiQC

```{figure} _static/figures/figure6_reporting.svg
:alt: Multiple prideQC mzQC files feeding pmultiqc and MultiQC to produce an interactive cross-run QC report, separately from SDRF refinement.
:width: 100%
:class: doc-figure

**Reporting is downstream of computation.** pmultiqc / MultiQC aggregates per-run mzQC documents into interactive plots; prideQC computes the QC values and refines SDRF metadata using the structured run summaries, not the HTML report.
```

prideQC writes machine-readable QC artifacts, while **pmultiqc / MultiQC** provide the interactive study-level reporting layer.

pmultiqc is a proteomics-focused MultiQC plugin that generates interactive HTML reports and visualizations from proteomics QC data. It builds on the MultiQC framework for aggregating many samples/runs into a single report.

- pmultiqc: <https://github.com/bigbio/pmultiqc>
- MultiQC: <https://seqera.io/multiqc/>

## prideQC reporting flow

```text
raw MS files
    │
    ▼
prideqc analyze
    │
    ├── *.summary.json
    ├── *.mzQC
    ├── metrics.tsv
    └── annotations.tsv
            │
            ▼
      pmultiqc / MultiQC
            │
            ├── multiqc_report.html
            └── multiqc_data/
```

The important interface is the mzQC-compatible output produced by prideQC. The reporting layer can aggregate many per-file QC documents without changing the scientific evidence generated by prideQC.

## Generate a report

When pmultiqc is installed alongside MultiQC, the generic mzQC reporting module can be run over a prideQC result directory:

```bash
multiqc --module mzqc \
  --outdir report \
  results/
```

A typical report directory contains:

```text
report/
├── multiqc_report.html
└── multiqc_data/
    ├── multiqc_data.json
    ├── multiqc_general_stats.txt
    └── ...
```

The exact files under `multiqc_data/` depend on the MultiQC version and enabled report content.

## Why reporting is separate from analysis

prideQC keeps the scientific QC runtime and visualization/reporting concerns separable:

- prideQC computes and serializes the evidence;
- pmultiqc / MultiQC render that evidence for interactive review;
- SDRF refinement consumes the structured evidence, not screenshots or HTML.

This separation makes the same QC results useful for both human review and automated downstream processing.
